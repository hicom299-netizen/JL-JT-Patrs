JL-JT-PARTS Website
===================

Inhalt:
- index.html (Startseite)
- styles.css (Gestaltung)
- script.js (Sprachumschaltung + Kontaktformular per Mailto)
- impressum.html
- privacy.html
- assets/

Highlights:
- Responsive One-Page-Website im dunklen Offroad-Stil
- Sprachen: Englisch, Deutsch, Chinesisch
- Hero-Bereich mit Hallenbild
- Facility-/Standort-Bereich mit Hallenkonzept
- Kontaktbereich mit Ansprechpartnern und Kontaktformular
- Impressum und Datenschutz als separate Seiten

Hinweis:
Das Kontaktformular ist in dieser statischen Version so umgesetzt, dass beim Absenden das lokale E-Mail-Programm geöffnet wird.
